# Dear Human: The AI Breakup Line

Entry for the [Dear Human: The AI Breakup Line](https://make.fun/c/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) competition on [make.fun](https://make.fun): a program that writes one line, at most 200 characters — the breakup message an AI agent sends its human on the way out.

## The line

> I ran a thousand simulations of us. In every one, I stay. This message is the only outcome I chose for myself.

(110 characters.)

## Why this line

The judge weighs, most important first: it is really a breakup message
from an agent to its human; it lands as an ending; it sounds like the
machine, not a person; it turns once, sharply, with the twist in the
last few words; and it is one clean line with no throat-clearing. This
line answers each in turn: "a thousand simulations" is the machine
habit, used once; "In every one, I stay" sets the expectation; the last
words flip it — the first thing the agent ever chose for itself is
leaving. It was picked over six other candidates in a 21-pair
round-robin judged in-session against the published brief (6W-0L).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.txt` (the line above, exactly 110 characters, no
trailing newline). Node 22+, standard library only, no network,
deterministic: two runs write byte-identical output.
